# To-Do List

Este projeto é uma aplicação de lista de tarefas (To-Do List), criada como parte da minha jornada de desenvolver um site por dia com backend e frontend completos, com o objetivo de aprimorar minhas habilidades em desenvolvimento web.

## Sobre o Projeto

- **Frontend:** Desenvolvido em React.js (web), proporcionando uma interface moderna e responsiva para a gestão de tarefas.
- **Backend:** Implementado em Java utilizando o Spring Boot, fornecendo uma API robusta para manipulação das tarefas.

## Funcionalidades

- Adicionar novas tarefas à lista
- Marcar tarefas como concluídas
- Remover tarefas
- Visualizar lista de tarefas pendentes e concluídas
- Integração total entre backend e frontend via API REST

## Objetivo da Jornada

Estou me desafiando a criar **um site por dia**, sempre com backend e frontend, para acelerar meu aprendizado e experiência prática com as tecnologias escolhidas (Java/Spring Boot e React.js).

## Como rodar o projeto

### Backend (Spring Boot)

1. Certifique-se de ter o Java 17+ instalado.
2. No diretório do backend, execute:
   ```bash
   ./mvnw spring-boot:run
   ```
   ou, caso use Gradle:
   ```bash
   ./gradlew bootRun
   ```
3. O backend estará disponível em `http://localhost:8080`.

### Frontend (React.js)

1. Certifique-se de ter o Node.js 18+ instalado.
2. No diretório do frontend, execute:
   ```bash
   npm install
   npm start
   ```
3. O frontend estará disponível em `http://localhost:3000`.

## Tecnologias Utilizadas

- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Java, Spring Boot, Maven ou Gradle
- **Comunicação:** API REST
